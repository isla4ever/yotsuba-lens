```text
Yotsuba Lens 网页设计证据采集
```

软件包中的摘要（由新 ZIP 自动带入）：

```text
采集网页设计证据、交互状态与缺口，支持设计参照与经授权重建。
```

说明：

```text
Yotsuba Lens 是一款面向设计师、产品经理和开发者的网页设计证据采集工具。用户主动发起智能捕获后，它会整理当前页面的布局结构、设计令牌、组件模式、交互状态、截图、动效线索和证据缺口。

你可以选择“设计参照”，提取可迁移的视觉和交互规律，用于原创设计；也可以在已获得授权时选择“经授权重建”，生成有边界、可验证的实现草案。侧边栏会清楚展示已捕获证据、缺失状态和下一步补充任务。

智能捕获只需一次操作，并会在超大或持续变化的页面上自动降级，避免页面卡顿。采集、存储和导出默认在本地完成，无需账号或 AI 配置即可导出证据包。只有用户主动配置兼容的 AI 服务并请求生成时，才会发送精简后的结构化证据。

Yotsuba Lens 不会自动运行在所有网页上，不会自动点击、输入、提交表单或跳转页面，也不会把未采集的状态描述为完整复刻结果。请仅在你有权查看和使用相关页面证据时进行采集。
```

类别：`开发者工具`

语言：`中文（简体）`

## 隐私权与审核

隐私权政策网址：

```text
https://github.com/isla4ever/yotsuba-lens/blob/main/docs/privacy.md
```

单一用途：

```text
Yotsuba Lens 的单一用途是：在用户主动操作时采集当前网页的布局、样式、截图和交互状态证据，并将其整理为设计参照或经授权重建所需的本地证据包。
```

### 权限理由

`activeTab`：

```text
仅在用户点击扩展按钮、智能捕获或选取组件时临时访问当前活动标签页，以读取当前页面并完成用户明确发起的采集。扩展不会在后台自动访问其他标签页。
```

`scripting`：

```text
当用户主动开始采集时，按需向当前标签页注入随扩展包发布的本地采集脚本，用于读取页面结构、计算样式和交互状态。不会注入或执行任何远程代码。
```

`storage`：

```text
在 Chrome 本地存储中保存界面语言、主题、采集设置、用户配置的 AI 服务资料、捕获历史、证据元数据和重建项目草稿，以便用户恢复工作区并导出证据。数据默认仅保存在本机。
```

`tabs`：

```text
用于识别用户当前活动标签页、读取其 URL 和标题、在标签页切换时刷新侧边栏状态，并在采集期间与当前页面通信和获取当前可见区域截图。不会用于跟踪与采集无关的浏览活动。
```

`sidePanel`：

```text
用于将捕获模式、采集进度、证据覆盖、历史记录和设置展示在 Chrome 原生侧边栏中，使用户在不离开当前网页的情况下操作和检查采集结果。
```

主机权限：

```text
用户可能需要在其有权分析的任意 HTTP 或 HTTPS 网页上采集设计证据，因此扩展需要访问用户当前选择的网站。访问只在用户主动发起捕获、选取组件或补采状态时发生；不会自动扫描所有网站，chrome:// 等受限页面会被拒绝。
```

### 远程代码

选择：`不，我并未使用远程代码`

如果后台仍显示理由输入框，填写：

```text
本扩展不使用远程代码。所有 JavaScript 依赖和采集逻辑均已打包在提交的软件包中，不通过 eval、new Function、远程 script 或远程模块执行代码。可选 AI 接口只交换结构化数据和文本结果，不下载或执行服务端返回的代码。
```

### 数据使用

只勾选以下四类：

- `身份验证信息`：仅包括用户自愿保存的可选 AI 服务 API Key；保存在 Chrome 本地存储中，并仅作为授权凭据发送给用户选择的 AI 服务商。
- `网络记录`：当前被捕获页面的 URL、标题和捕获时间，用于标识历史记录、路由证据和导出文件。
- `用户活动`：用户主动采集期间观察到的滚动、悬停、聚焦、打开和时间证据；输入值会被遮罩。
- `网站内容`：可见文本片段、DOM 结构、计算样式、布局指标、资源地址和用户主动获取的截图。

不要勾选：`个人身份信息`、`健康信息`、`财务和付款信息`、`个人通讯`、`位置`。

数据使用声明：

```text
身份验证信息：仅处理用户自愿配置的可选 AI 服务 API Key，密钥保存在 Chrome 本地存储中，并仅发送给用户选择的 AI 服务商完成其主动请求。网络记录：仅保存用户主动捕获页面的 URL、标题和时间。网站内容：采集可见文本片段、设计令牌、布局指标、资源地址、截图和脱敏证据。用户活动：仅在用户主动发起的采集会话中观察滚动、悬停、聚焦、打开和时间证据，输入值会被遮罩。数据仅用于采集、分析、本地存储、导出和用户主动请求的 AI 生成，不出售、不用于广告、不用于信用评估，也不用于无关用途。
```

勾选下面三项确认：

- 不会出于已获批准的用途之外的其他目的向第三方出售或传输用户数据。
- 不会将用户数据用于或传输至与该产品单一用途无关的目的。
- 不会将用户数据用于或传输至信用评估或贷款目的。

审核测试说明：

```text
1. 安装标准版扩展，不需要账号。
2. 打开普通公开 HTTPS 网页，点击工具栏中的 Yotsuba Lens，侧边栏应默认打开。
3. 保持“设计参照”模式，点击“智能捕获”，等待结果出现在侧边栏。
4. 打开“覆盖”和“历史”查看证据状态。
5. 导出证据包；此流程不需要 AI 密钥。
6. 仅在获得授权时选择“经授权重建”，确认授权后再测试重建证据。
扩展不会自动导航、提交表单或执行合成点击；chrome:// 等受限页面会被拒绝。
```
